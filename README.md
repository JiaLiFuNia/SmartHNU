## 简介

师韵 SmartHNU 是一款基于 `Android` 平台的校园生活助手，集新闻阅览、教务信息、图书查询、教室查询于一体，旨在为河南师范大学本科生及新生提供便捷的校园服务。

本应用采用 `Kotlin` 语言编写，使用 `Jetpack Compose` 组件库，遵循 `Material Design` 设计规范。

## 使用

在使用本应用时，登录密码会被加密后存储在本地。其余信息均为实时获取，不会被存储。由于登录令牌具有有效性，故存储的密码将用于当令牌失效时自动重新登录。
